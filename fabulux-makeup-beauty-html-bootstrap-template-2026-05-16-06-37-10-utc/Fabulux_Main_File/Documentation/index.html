Introduction

Thank you for purchasing Fabulux! Fabulux is a modern and elegant HTML5 Bootstrap template designed for Makeup Artists, Beauty Salons, Spas, and other beauty-related businesses. This creative template is perfect for showcasing your beauty services, makeup portfolios, beauty blogs, skincare products, cosmetic stores, and more. Whether you're running a beauty salon, freelance makeup business, or beauty academy, Fabulux provides a clean, stylish layout with a professional design and smooth user experience, helping you present your services and products in the most appealing way possible.

Requirements

Before editing or customizing Fabulux, please make sure you have the following tools installed:

  • Code Editor — Recommended: Visual Studio Code
  • Modern Browser — Chrome, Edge, Firefox, Safari, or Opera
  • Basic HTML/CSS/JS Knowledge — To customize and edit template files

Installation

Follow these steps to start using the Fabulux template:

  1. Unzip the downloaded .ontra.zip file.
  2. Open the extracted folder in your preferred code editor (we recommend Visual Studio Code).
  3. You can open any .html file directly in your browser to preview the template. However, we highly recommend using the Live Server extension in Visual Studio Code to view the template locally. This ensures that all JavaScript animations, sliders, and interactive elements work properly.
  4. All CSS, JS, and fonts are already linked — no build or compilation is required.

Dependencies

Fabulux includes the following libraries and frameworks:

- Swiper JS Slider

All these dependencies are already included in the assets/js and assets/css folders or loaded via CDN.
